Census Data Analysis Tool

Using open-source tools for data fetching, processing, and visualization

Introduction to the Tool

This presentation showcases a powerful data analysis tool built in Google Colab that:

  • Fetches data directly from the US Census Bureau API
  • Processes and transforms the data using Pandas
  • Creates interactive visualizations with Folium
  • Generates both tract-level and municipality-level insights
Google Colab Environment

The tool is designed for researchers, data analysts, and anyone interested in exploring demographic data.

Key Features

Data Fetching

Retrieves data directly from the Census API with user-selected variables and years

Data Processing

Uses Pandas to clean, merge, and calculate derived metrics like per-capita values

Interactive Mapping

Creates choropleth maps with Folium for visual data exploration

Multiple Geographic Levels

Analyzes data at both census tract and municipality levels

Data Fetching Process

The tool connects to the Census API to fetch data:

# Example of data fetching code import requests import pandas as pd variable = 'B01001_001E' # Total population year = '2020' url = f"https://api.census.gov/data/{year}/acs/acs5" params = { "get": f"NAME,{variable}", "for": "tract:*", "in": "state:44" # Rhode Island } response = requests.get(url, params=params) data = response.json() df = pd.DataFrame(data[1:], columns=data[0])
Users can select from a dropdown of available census variables and specify the year of data they want to analyze.

Data Processing with Pandas

The tool processes the data to create meaningful metrics:

# Calculate per-capita values df[variable] = pd.to_numeric(df[variable], errors='coerce') df['population'] = pd.to_numeric(df['population'], errors='coerce') df[f"{variable}_per_capita"] = (df[variable] / df['population']) # Create GEOID for mapping df['GEOID'] = df['state'] + df['county'] + df['tract']

Key processing steps:

  • Data type conversion for numerical operations
  • Calculation of derived metrics (per-capita values, percentages)
  • Creation of geographic identifiers for mapping
  • Merging with population data for normalization

Visualization with Folium

The tool creates interactive choropleth maps:

Users can toggle between viewing raw values or per-capita rates, providing different perspectives on the data.

Multi-level Analysis

The tool provides insights at different geographic levels:

Census Tract Level

High-resolution analysis of small areas within municipalities

Municipality Level

Aggregated data for entire cities and towns for broader comparisons

# Example of municipality aggregation agg_df = gdf_merged.groupby("MUNICIPALI").agg({ variable: 'sum', 'population': 'sum' }).reset_index() agg_df[f"{variable}_per_capita"] = (agg_df[variable] / agg_df['population'])

This dual-level approach allows users to zoom in on neighborhood-level patterns or compare broader municipal trends.

Benefits and Applications

This tool provides significant advantages:

  • Accessibility: No specialized software needed - runs in any web browser with Google Colab
  • Cost-effective: Uses entirely free and open-source tools
  • Reproducible: Complete workflow from data acquisition to visualization
  • Customizable: Easy to modify for different variables, regions, or analysis types
  • Time-saving: Automates the entire data processing pipeline
Potential applications include urban planning, academic research, policy analysis, business intelligence, and community advocacy.
