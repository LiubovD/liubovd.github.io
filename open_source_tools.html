Open Source Census Data Workflow

From Census API to Interactive Maps with Python

Why Open Source for GIS?

  • Accessible: no license costs, community-driven
  • Flexible: customizable workflows in Python
  • Transparent: reproducible and sharable code
  • Scalable: from small projects to big data

Our workflow uses Pandas, GeoPandas, Folium, and the Census API — all 100% open source.

Workflow Overview

  1. Fetch demographic data via Census API
  2. Clean & transform with Pandas/GeoPandas
  3. Aggregate by tracts or municipalities
  4. Map interactively with Folium
Entire pipeline is reproducible and runs in Jupyter or Google Colab.

Open Source in Action

Example: Fetching Census data with requests and pandas:

import requests, pandas as pd url = "https://api.census.gov/data/2020/acs/acs5" params = {"get":"NAME,B01001_001E", "for":"tract:*", "in":"state:44"} response = requests.get(url, params=params) df = pd.DataFrame(response.json()[1:], columns=response.json()[0])

From here, the workflow moves to cleaning, aggregating, and mapping.

Interactive Mapping with Folium

Folium (Python wrapper for Leaflet.js) lets us build web-ready interactive maps:

import folium m = folium.Map(location=[41.58, -71.47], zoom_start=9) folium.Choropleth( geo_data=geojson_data, data=df, columns=["GEOID", "population"], key_on="feature.properties.GEOID", fill_color="YlOrRd", legend_name="Population" ).add_to(m)

Maps can be shared online or embedded in web apps — no proprietary software required.
