Census Data Analysis Tool

Using open-source tools for data fetching, processing, and visualization

Introduction to the Tool

This presentation showcases a powerful data analysis tool built in Google Colab that:

  • Fetches data directly from the US Census Bureau API
  • Processes and transforms the data using Pandas
  • Creates interactive visualizations with Folium
  • Generates both tract-level and municipality-level insights
Google Colab Environment

The tool is designed for researchers, data analysts, and anyone interested in exploring demographic data.

What is Google Colab?

  • Free cloud-based Python environment
  • Instant access to CPUs, GPUs, and TPUs
  • No installation required — runs in your browser
  • Supports data analysis, machine learning, and visualization workflows
  • Integrates easily with Google Drive, GitHub, and external datasets
  • Ideal for collaborative projects and reproducible workflows

APIs & Python Requests

  • API (Application Programming Interface): enables software to communicate and exchange data
  • Provides a standard way to request and receive data from a service
  • Example: US Census Bureau API provides demographic and geographic data
  • Python requests library:
    • Sends HTTP requests to APIs
    • Retrieves data in formats like JSON
    • Enables automation and reproducibility in workflows
  • Integrates with Pandas/GeoPandas for further processing and analysis

Pandas & GeoPandas

  • Pandas: data manipulation and analysis of tabular data
  • Filtering, grouping, merging, and aggregating datasets
  • GeoPandas: extends Pandas to handle geospatial data (shapefiles, GeoJSON, spatial dataframes)
  • Supports spatial operations: intersections, joins, buffering, and plotting
  • Enables efficient processing, analysis, and visualization of geospatial datasets

What is Folium?

  • Python library for creating interactive maps using Leaflet.js
  • Visualize geospatial data in Jupyter Notebook or Colab
  • Supports markers, popups, choropleths, and heatmaps
  • Integrates with Pandas and GeoPandas for mapping dataframes
  • Other similar open-source tools: Leaflet.js, Kepler.gl, Plotly, Matplotlib/Basemap
